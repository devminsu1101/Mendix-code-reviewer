# Mendix Code Reviewer Roadmap

이 문서는 Mendix 모델 분석 도구의 현재 상태와 향후 AI 기반 시니어 코드 리뷰 및 MS Teams 연동을 위한 발전 방향을 정리합니다.

## 1. 현재 상태 (Current State)
현재 프로젝트는 Mendix 모델을 읽고 정해진 규칙에 따라 정적으로 분석하는 기초 엔진을 갖추고 있습니다.

- **분석 엔진**: `domain.ts`, `logic.ts`, `page.ts`를 통해 Mendix의 핵심 요소 탐색 가능.
- **규칙 기반**: `rules.ts`에 정의된 정적 규칙(예: 루프 내 조회 등)을 바탕으로 결함 탐색.
- **AI 연동 기초**: `onboarding_ai.ts`를 통해 Gemini API와 통신하여 프로젝트 특성 파악 가능.
- **리포팅**: `reporter.ts`를 통한 텍스트 기반 결과 출력.

## 2. 향후 발전 방향 (Future Direction)
단순한 문법 체크를 넘어, 비즈니스 로직의 결함을 짚어내고 팀에 자동으로 공유하는 '가상 시니어 개발자' 시스템 구축을 목표로 합니다.

| 기능 영역 | 신규/수정 모듈 | 핵심 목표 |
| :--- | :--- | :--- |
| **트리거** | `src/client.ts` 수정 | Git 커밋/머지 이벤트 발생 시 자동 실행 |
| **변경분 추출** | `diff_engine.ts` (신규) | 전체가 아닌 '변경된 객체'만 정밀 분석하여 효율성 극대화 |
| **맥락 파악** | `context_engine.ts` (신규) | 로직이 어떤 비즈니스 페이지/기능과 연결되는지 AI에게 전달 |
| **로직 요약** | `logic.ts` 수정 | 마이크로플로우를 AI가 이해할 수 있는 '이야기'로 변환 |
| **AI 리뷰** | `review_ai.ts` (신규) | 아키텍처 및 비즈니스 리스크 중심의 시니어급 인사이트 도출 |
| **알림 전송** | `teams_notifier.ts` (신규) | MS Teams Adaptive Cards를 통한 시각적 리포트 공유 |

## 3. 핵심 시나리오: "Smart Business Review"
1. **Push 감지**: 개발자가 `dev` 브랜치에 코드를 올림.
2. **Delta 분석**: 변경된 마이크로플로우와 그 영향 범위를 자동으로 계산.
3. **Narrative 생성**: "이 로직은 결제 확인 페이지에서 사용되며, 할인율을 계산함"이라는 맥락 추출.
4. **AI 전문 리뷰**: Gemini가 "할인율 적용 순서가 세금 계산보다 앞서 있어 회계 정책 위반 위험이 있음"을 발견.
5. **Teams 알림**: 팀원들이 모여 있는 톡방에 즉시 가이드라인 카드 전송.

## 4. 실행 계획
- **1단계**: Mendix SDK Compare 기능을 활용한 증분 분석(Diff) 로직 구현.
- **2단계**: 마이크로플로우 로직을 텍스트로 요약하여 AI에게 전달하는 프롬프트 최적화.
- **3단계**: MS Teams Incoming Webhook 연동 및 Adaptive Card 포맷터 개발.
